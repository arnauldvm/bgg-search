## [0.1.0] - 2026-06-07

### Added

- Initial release of `bgg-search`: a Python client and CLI for the BoardGameGeek XML API.
- Package installable from PyPI; requires Python ≥ 3.13.
- `bgg_search.__version__` exposes the installed package version.
